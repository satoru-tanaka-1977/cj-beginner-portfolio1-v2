# Photographer Portfolio（ポートフォリオサイト） [2周目]

CODEJUMP 初級編の「ポートフォリオサイト（1カラム）」課題として制作しているWebサイトです。

## 概要

「東京の西麻布を拠点に活動するフォトグラファーからの依頼」という案件設定のもと、ポートフォリオ用のWebページ（1ページ）を制作しています。

仕様書やデザインカンプから意図を読み解き、検証ツールに頼りすぎず、最適なHTML構造・CSSレイアウトを自力で設計・構築する実践練習を行っています。

## コーディング仕様

- **コンテンツ幅**: コンテンツ領域 max-width 960px（横パディング 4%）※メインビジュアルのみ全幅
- **メインビジュアル**: 全幅（width: 100%）、高さ 420px 固定
- **About**: テキスト中心のエリア（住所ブロックとプロフィールブロックで構成）
- **Works**:
  - 画像の横並び配置（フレックスボックスでの折り返し制御）
  - スマホ表示時は 1列縦並び
- **News**:
  - 日付とタイトルを横並びのリスト形式で配置
  - スマホ表示時は 縦並び配置
- **Contact**:
  - ラベルと入力フィールドの横並びフォームレイアウト
  - 送信ボタンのホバーエフェクト（背景色・文字色の反転）
- **レスポンシブ対応**: ブレークポイント 600px

## 使用技術
